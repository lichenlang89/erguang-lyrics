# 耳光乐队歌词整理

听众发起的耳光乐队歌词人工转录与校对项目，保存现场唱词、不同版本、未听清的疑词，以及歌词涉及的人物、典故和历史事件。

这里的歌词是持续修订的工作稿，不是官方定稿。欢迎中文 Issue 和 PR：哪怕只听清一个字，也欢迎补充。

检索名称：**耳光乐队、耳光樂隊、耳光、赵荒唐、十八系列、现场歌词、歌词听写、歌词校对**。乐队拼音为 `erguang`，英文名为 `Slap`。歌曲条目及版本见下方目录；程序化读取可使用[曲目索引](曲目索引.json)，GitHub 搜索示例见[检索说明](检索说明.md)。

## 关于耳光乐队

耳光乐队于 1998 年成立于河北保定，主唱赵荒唐。早期音乐介绍将其风格称为「新民俗主义」，音乐中结合民间旋律、曲艺表达与摇滚、放克等元素。可参阅[早期迷笛音乐节介绍](https://ent.sina.com.cn/p/i/2003-09-23/1429205349.html)、[二〇〇七年乐队介绍](https://ent.sina.cn/music/2007-04-21/detail-icesifvy0209051.d.html)和[主唱访谈资料](https://www.chinadigitaltimes.net/space/%E8%80%B3%E5%85%89%E4%B9%90%E9%98%9F)。

本库收录的「十八系列」等歌曲，经常把古典小说人物、年度新闻、网络热词、广告词和谐音包袱串成故事。歌词中的不通顺、粗口或角色错位，有时正是有意的表达；不同现场也可能整段改词。理解这些歌词，需要实际回听，也需要核对当年的语境。

据[中国数字空间的资料汇编](https://www.chinadigitaltimes.net/space/%E8%80%B3%E5%85%89%E4%B9%90%E9%98%9F)，乐队在 2023 年遭遇网络封禁。这也是维护者持续进行人工转录、保存唱词的背景。关于封禁经过应结合具体来源阅读，不把这一概述当成所有平台现状的说明。

## 我们怎样整理

1. **先听写，再核对。** 人工听写为主，工具协助查证人物、典故和历史细节；工具提出的候选词不等于实听结果。
2. **保留现场版本。** 改词、口误、衬词、重复都应照实记录，同名歌不强行合并。
3. **听不清就留下来。** 可以保留拼音、问号和多个候选，附时间点等待共同回听。
4. **正文与考据分开。** 歌词保留工作稿，证据、猜测和版本说明写入「考据」。
5. **历史细节附来源。** 区分已证实事实、当年的指控或舆论、歌词中的反讽；上传日期不当作演出日期。

## 如何提交修正

不熟悉 Git 也可以直接在 [Issues](https://github.com/lichenlang89/erguang-lyrics/issues) 选择「歌词修正」，写清歌名、原句、建议改法、音视频来源和时间点。拿不准就标注推测。

愿意直接改文件，可以 Fork 仓库，修改对应文本，再通过 [Pull requests](https://github.com/lichenlang89/erguang-lyrics/pulls) 提交 PR。请用中文解释改了什么、为什么改，尤其要说明是否为同一场现场。

详细步骤、版本命名及考据格式见 [如何参与校词](CONTRIBUTING.md)。不需要一次转录整首；来源补充、疑音讨论、纠正错误考据同样欢迎。
